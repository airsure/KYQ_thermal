## 修复主目录运行 hp_thermal.py 报 FileNotFoundError
- 原因: VS Code 默认 cwd 为用户主目录, 相对路径 'INB.DAT' 找不到。
- 修复: __main__ 默认输入/输出路径改为基于脚本所在目录(os.path.dirname(os.path.abspath(__file__)))拼绝对路径; 显式传参时用参数。
- 附带改进: stage25 增加 qh<=0 防护与热平衡迭代 tfcc<TFJC 下限防护(物理不可能状态, 与"上限不可限"不同), 基准 INB.DAT 校核工况(新 U 公式下不匹配)现在给出明确中文原因而非温度越界报错。
- 验证: 主目录运行可读到 INB.DAT; 测试数据工况正常生成 OUT_PY.DAT; 回归 17.58/9x9 不变; hp_gui 导入正常。
## PyInstaller 打包 GUI 为 exe（含图标）
- favicon.ico 放在项目根目录; hp_gui.spec 增加 icon='favicon.ico'，console=False 单文件模式。
- 打包命令: env3.8 的 python -m PyInstaller hp_gui.spec --noconfirm（PyInstaller 6.17.0）。
- 产物: dist/hp_gui.exe（约 55MB）。试运行验证进程正常启动（tasklist 可见），测试后已结束。
- 注意: 打包以 hp_gui.spec 为准，改代码后需重新打包；运行 exe 时工作目录即 exe 所在目录的上一级(INB.DAT 自动载入基于 HERE=脚本目录, 打包后为 sys._MEIPASS 临时目录, INB.DAT 不会打进包, GUI 启动时 INB.DAT 载入失败仅状态栏提示, 不影响手填/导入)。
