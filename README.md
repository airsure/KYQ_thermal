# 热管式空气预热器热力计算程序（KYQ_thermal）

> 矩形烟道热管式空气预热器（气‑气换热器）的**设计计算**与**校核计算**程序。
> 源于 2000 年的 Fortran 77 程序 `HP.FOR` / `HP.EXE`（THERP 物性库），
> 现提供 **Python 复现版** + **PyQt5 图形界面** + **可执行程序打包**。

适用于小化肥吹风气余热回收等高温烟气—空气换热场景，计算换热面积、管束布置、
换热系数、出口温度与两侧压降。

## 1. 项目简介

本程序用于**矩形烟道热管式空气预热器**的传热计算，针对小化肥吹风气余热回收
热管空气预热器的工艺参数编制（原始说明见 [`readme.txt`](readme.txt)，2000‑08‑10）。

技术演进路线：

| 阶段 | 形态 | 说明 |
| --- | --- | --- |
| 2000‑08 | `HP.FOR` → `HP.EXE` | Fortran 77 主程序 + THERP 物性库（`HP.OBJ`），固定列宽数据文件 |
| 现在 | `hp_thermal.py` | Python 复现，物性改用 CoolProp，算法结构逐条对应原源码 |
| 现在 | `hp_gui.py` | PyQt5 图形界面，表格显示、导出 Excel/CSV、与原程序对比列 |
| 现在 | `hp_gui.spec` | PyInstaller 单文件打包，产出免安装 exe |

Python 版保留原程序的**迭代结构**（热平衡回路、温度交叉检查、校核面积回路）
与**输出项编号**，因此可以逐项与原程序输出对比。

## 2. 功能特性

- **两种计算类型**（由 `INB.DAT` 第 13 行 `KT` 控制）
  - `KT = 1`：**校核计算** — 给定管束布置（横向根数 `IBH`、纵向排数 `IMH`），
    迭代求热侧出口温度，使所需面积与实际面积偏差 < 0.5%
  - `KT ≠ 1`：**设计计算** — 由迎风面设计流速反推迎风面宽度与横向管数，
    再求所需排数
- **混合气体物性**：CoolProp HEOS 混合物模型（N₂/O₂/H₂/CO/CO₂/COS/CS₂/SO₂/H₂S/H₂O/CH₄），
  密度按理想气体状态方程 `P·M/(R·T)` 计算，与原程序的 `Nm³/22.4` 标况基准一致
- **可选的 THERP 校准**：通过 `CALIB.JSON` 按侧（热侧 `h` / 冷侧 `c`）修正
  `rho/mu/cp/k` 四个物性因子，使 Python 输出对齐 1985 年 THERP 库的物性取值；
  删除该文件即回到**纯 CoolProp 物理直算**
- **自动对比**：目录下存在 `OUT.DAT`（原程序输出）时，命令行与 GUI 都会给出
  逐项偏差表（GUI 中 ≥1% 橙色、≥5% 红色）
- **健壮性防护**：迭代次数上限、温度越界检测，并以**中文**给出可读的失败原因
  （而不是抛出 CoolProp 内部错误）
- **导出**：Excel（输入参数 + 计算结果双工作表）与 CSV（`utf-8-sig`，Excel 直接可读）


```powershell

python hp_thermal.py 我的工况.dat 结果.dat   # 指定输入/输出文件
```

程序会自动在脚本所在目录寻找 `INB.DAT` / `OUT_PY.DAT`，因此**在任意工作目录下
运行都能找到输入文件**。若同目录存在 `OUT.DAT`，会额外打印与原程序的逐项对比表：

```
序号   项目                    HP.EXE         Python      偏差%
4      热侧气体出口温度          749.00         748.97    -0.00%
31     传热系数                   32.20          32.24    +0.13%
...
```

### 4.3 图形界面

```powershell
python hp_gui.py          # 直接运行
```

或双击 [`启动计算界面.bat`](启动计算界面.bat)（用 `pythonw` 启动，无黑窗口）。

界面构成：

- **左侧参数区**：组分编号（7 个，热/冷侧共用）、热侧气体、冷侧气体、换热管参数、
  热侧翅片、冷侧翅片、迎风面流速/材料/污垢，以及计算类型单选（`KT=1` 校核 / `KT=0` 设计）
- **右侧结果表**：序号 / 项目 / 单位 / 数值；当前输入与 `OUT.DAT` 基准工况

## 5. 输入文件 INB.DAT 格式

`INB.dat` 为 **13 行定长格式**数据文件，字段宽度与原程序 `FORMAT` 语句一一对应。
数值字段内的空格按 Fortran 默认 `BLANK='NULL'` 语义忽略。

| 行 | 内容 | 字段 |
| --- | --- | --- |
| 1 | 7 种组分编号 | 各 2 位整数 |
| 2 | 固定 4 个 0 | THERP 程序要求 |
| 3 | 热侧（烟气）流量 Nm³/h、压力 kgf/cm²(绝压) | `F12.1`, `F8.1` |
| 4 | 热侧进、出口温度 ℃（出口为**初值**） | `F8.1` ×2 |
| 5 | 热侧换热段长度 mm、翅片高度 mm、翅片厚度 mm、翅片节距 mm | `F7.1 F5.1 F5.1 F5.1` |
| 6 | 光管外径 mm、光管内径 mm、横向节距 mm、斜向节距 mm | `F5.1 F5.1 F6.1 F6.1` |
| 7 | 热侧按组分编号顺序的体积百分数 %（7 项） | `F6.2` ×7 |
| 8 | 冷侧（空气）流量 Nm³/h、压力 kgf/cm²(绝压) | `F12.1`, `F8.1` |
| 9 | 冷侧进、出口温度 ℃（出口为**初值**） | `F8.1` ×2 |
| 10 | 冷侧换热段长度、翅片高度、翅片厚度、翅片节距 mm | `F7.1 F5.1 F5.1 F5.1` |
| 11 | 冷侧组分体积百分数 %（7 项） | `F6.2` ×7 |
| 12 | 迎风面设计流速 m/s、翅片导热系数 W/(m·K)、管壁导热系数 W/(m·K)、热侧污垢热阻 m²·K/W、冷侧污垢热阻 m²·K/W、蒸发换热系数 W/(m²·K)、冷凝换热系数 W/(m²·K) | `F5.1 F5.1 F5.1 F8.5 F8.5 F8.1 F8.1` |
| 13 | 横向根数、纵向列数、计算类型标识 `KT`（1=校核，非 1=设计） | `I5` ×3 |

### 组分编号表

| 编号 | 组分 | 编号 | 组分 |
| --- | --- | --- | --- |
| 01 | N₂ 氮 | 07 | CS₂ 二硫化碳 |
| 02 | O₂ 氧 | 08 | SO₂ 二氧化硫 |
| 03 | H₂ 氢 | 09 | H₂S 硫化氢 |
| 04 | CO 一氧化碳 | 12 | H₂O 水蒸气 |
| 05 | CO₂ 二氧化碳 | 13 | CH₄ 甲烷 |
| 06 | COS 氧硫化碳 | | |

> **解析兼容性**：手工编辑的输入文件常常列宽不对齐，固定列宽切分会把数字切成两半
> （例如 `0.00035` 被切成 `0.0003` 与 `50.0`）。因此 `parse_line()` 在“按空白切分
> 恰好得到字段数且全部为合法数字”时优先按空白切分；含空缺字段（空格补位表示 0）
> 的正规文件仍走固定列宽解析。

### 基准工况（仓库内 `INB.dat`）

热侧烟气 88600 Nm³/h，805 ℃ → 745 ℃；冷侧空气 17000 Nm³/h，150 ℃ → 500 ℃；
热侧为光管段（翅片节距 999 mm），冷侧翅片节距 6 mm；`KT=1` 校核，管束 30 × 10。

## 7. 计算原理与迭代流程

主流程与迭代结构与 `HP.FOR` 严格对应（源码 `label` 号保留在注释中）：

```
读入 INB.DAT
   │
   ├─ label 25 段（外层可重入）
   │    ├─ FPROP 求热侧物性 → QH = VFH·WM/22.4·cp·(TFJH − TFCH)   热侧放热量
   │    ├─ QC  = 0.97 × QH      传热量（第一级散热损失）
   │    ├─ QC1 = 0.97 × QC      冷侧应吸热量（第二级）
   │    └─ label 30  热平衡迭代：调冷侧出口温度 TFCC，直到 |DQ| ≤ 1%
   │
   ├─ label 800 温度交叉检查：要求 TFJH > TFCC，否则拉低 TFCH 整体重算
   │
   ├─ label 801 对数平均温压 DTM（逆流/叉流按端差取 LMTD）
   │
   ├─ 迎风面：AEXH = VFH/22.4·WM/RO/3600/WN → 宽度 EH → 横向管数 IB
   │            （校核计算取输入值 IBH；设计计算由流速反推）
   │
   ├─ label 40
   │    ├─ AHFA  气侧换热系数（最小流通面积法）
   │    │     HNAF = ((ST − DO) − 2·HF·DTA/SF)/1000 · AL/1000 · IB
   │    │     GMAX = VF/22.4 · WM / HNAF           最大质量流密度 kg/(m²·h)
   │    │     RE   = GMAX·DO/3600/1000/μ
   │    │     Nu   = 0.137 · Re^0.6338 · Pr^(1/3)   错排管束关联式
   │    │     AHF  = 1000·k/DO · Nu                 W/(m²·K)
   │    ├─ AHFE  环形翅片效率（悬臂肋近似）
   │    │     ZZ   = (HF/1000)·(2000·AHF/(λ_f·DTA))^0.5
   │    │     η    = tanh(ZZ)/ZZ × 0.9
   │    │     HFE  = AHF · (AR + η·AF) / AH         有效换热系数
   │    ├─ 传热系数 UFH（见下方“重要说明”）
   │    ├─ AHHH = QC / UFH / DTM / 3.6              所需换热面积 m²
   │    ├─ BN   = AHHH / AHH / (ALH/1000) → BM → IM 所需排数
   │    └─ 校核计算（KT=1）：实际面积
   │          AHH1 = AREA(…)×(IBH·IMH − IMH/2)×ALH/1000
   │          DAHH = (AHHH − AHH1)/AHH1
   │          若 |DAHH| < 0.5% → 收敛；否则调 TFCH 后 goto label 25
   │
   ├─ label 64 管束与压降
   │    ├─ N = IB·IM − IM/2                          错排布置，隔排少一根
   │    ├─ 压降 DETP：F = 1.92/Re^0.145，含壁温粘度修正 (μ/μ_w)^0.14
   │    └─ 输出 39 项
```

### 重要说明：传热系数公式

自 **2026‑09‑23** 起，传热系数按用户指定的修正公式计算：

```
UFH = 1 / ( 1/HFEH + 1/HFEC × ALH/ALC )
```

即**只取热侧/冷侧有效换热系数**，冷侧按换热段长度比折算到热侧基准；
**不再计入**污垢热阻、管壁热阻、蒸发/冷凝热阻等串联热阻项（原 `HP.FOR` 的模型）。

由此带来的两个必然结果：

1. 输出第 **31 项（传热系数）** 与原 `HP.EXE` 的 `OUT.DAT` **不再可比**，对比列中
   该项的大偏差属预期差异；第 29/30 项（两侧有效换热系数）仍完全可比。
2. 仓库内的基准工况 `INB.dat`（`KT=1` 校核，热侧光管、`ALH/ALC ≈ 9.66`）在新模型下
   `UFH` 由 32 降到约 3.6，所需面积约 1483 m² 而实际仅 148 m²，**校核迭代会发散**，
   程序给出发散原因的中文提示。**这属于预期行为**：同一组数据用设计计算（`KT=0`）
   可正常收敛，结果为 49 × 80 排、共 3880 根管。

## 8. 物性模型与 THERP 校准

### 8.1 物性来源

| 物性 | 来源 |
| --- | --- |
| 分子量、比热、粘度、导热系数 | CoolProp `HEOS` 混合物模型 |
| 密度 | 理想气体状态方程 `ρ = P·M/(R·T)`（与原程序标况基准一致） |
| 普朗特数 | `Pr = cp·μ/k` |

实现要点：

- 混合物用 `AbstractState('HEOS', 'Nitrogen&Oxygen&…')` + `set_mole_fractions()`，
  并**显式指定气相** `specify_phase(iphase_gas)`。烟气/空气在约 1 atm、全工况温度
  范围内均为过热气体，显式指定气相可绕开 CoolProp 6.4.3 混合物 PT 闪算定相判定
  缺陷（过热区也可能抛 `One stationary point (not good)`，见 CoolProp issue #2004）。
- **CoolProp 6.4.3 兼容补丁**：该版本缺少 SO₂ 与 N₂/H₂/CO/H₂O 的二元交互参数，
  且不含 CO / SO₂ 的纯组分输运数据（6.6.0 才补入）。程序会
  ① 为缺失二元对自动补 `linear` 混合规则（补规则前必须先创建一次普通混合物以触发
  内置二元对库的懒加载，否则库会被“钉死”）；② 输运性质失败时回退到
  **Wilke 粘度混合规则 + Wassiljewa‑Mason‑Saxena 导热混合规则**，并为 CO / SO₂
  补 Sutherland 粘度式与线性导热关联式（约 273~650 K，±3%）。

### 8.2 THERP 校准（可选）

```powershell
python calibrate.py
```

以 `OUT.DAT` 为基准，对 8 个物性因子做带阻尼（0.7）的不动点迭代，收敛判据为
最大残差 < 0.05%，结果写入 `CALIB.JSON`：

```json
{ "h": { "rho": 1.0297, "mu": 0.9531, "cp": 0.9799, "k": 0.9380 },
  "c": { "rho": 1.0356, "mu": 0.9627, "cp": 1.0158, "k": 0.9655 } }
```

灵敏度更新规则：

| 因子 | 依据 |
| --- | --- |
| `f_rho` | `WW ∝ 1/ρ` |
| `f_mu` | `Re ∝ 1/μ` |
| `f_cp` | `QH ∝ cp·ΔT` |
| `f_k` | `HFE ≈ ∝ k^(2/3)`，取指数 1.5 |

语义为 `THERP 物性值 = f × CoolProp 物性值`，分热侧 / 冷侧独立修正。
**删除 `CALIB.JSON` 即回到纯 CoolProp 物理直算模式。**

## 9. 与原版 HP.EXE 的对比验证

校准后 39 项逐项对比（基准工况 `INB.dat` + `OUT.DAT`）：

- 几何量与管数**精确命中**：`N = 295` 根，换热面积 `148.2 m²`（+0.01%）
- 出口温度：`748.97 / 474.29 ℃` vs 原程序 `749.0 / 474.1 ℃`
- 换热系数：`39.60 / 37.80 W/(m²·℃)` 精确命中
- 压降：`+0.27% / −0.10%`
- 除第 36/37 项（`OUT.DAT` 只印 1 位小数造成的显示伪差）与第 31 项（见上文公式变更）
  外，其余各项偏差 ≤ 0.27%

未使用校准时的差异来源（约 +1.65% ~ +5%）已定位为**物性模型代差**：

- 1985 年 THERP 关联式与 CoolProp 模型的 μ 相差约 4.5% → Re 偏低 4.3~4.7%
- THERP 把 `1 kgf/cm²` 近似按 `1 atm` 处理 → 密度差 2.9%

结论：**算法结构转换完全正确**，残差属物性模型代差；纯 CoolProp 模式物理上更准，
THERP 校准模式则用于逐项复刻 2000 年原程序的输出。

## 10. 已知问题与注意事项

1. **基准工况在校核模式下发散**：见 [第 7 节重要说明](#重要说明传热系数公式)。
   如需复刻原程序结果，请使用旧的串联热阻模型，或改用设计计算 `KT=0`。
2. **文件编码**：`INB.dat` 按 ASCII 读取；`OUT.DAT` / `OUT_PY.DAT` 为 **GBK** 编码，
   用记事本以外的一般编辑器打开需注意编码设置。
3. **第 12 行污垢热阻需 5 位小数**（如 `0.00035` / `0.00005`），取整会明显改变
   收敛结果。列宽不对齐时依赖自由格式回退解析。
4. **热平衡迭代的暂态越界**：迭代过程中冷侧出口温度可能瞬时大幅越过热侧进口温度
   （大工况下可达约 1100 ℃），这是原算法行为，外层温度交叉检查会把它拉回。
   因此防护只限**迭代次数**，不限**区间**；但低于冷侧进口温度属物理不可能状态，
   一旦出现即判为热平衡无解并给出中文原因。
5. **Python 3.13 + CoolProp 8**：解释器退出阶段可能崩溃（`EXIT=0xC0000409`），
   脚本结尾用 `os._exit(0)` 规避，不影响计算结果。
6. **GUI 输入校验**：`QLineEdit.setText()` 会绕过 validator（Qt 行为），程序内部
   写入的均为格式化数字，无影响；validator 只拦截用户键入。
7. **exe 打包**：`INB.DAT` 不打进包内，运行 exe 时需自行填写或手动导入；修改代码后
   需重新执行 PyInstaller。
